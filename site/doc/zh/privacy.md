# 隐私说明

Pairfob 将已配对的浏览器连接到运行 Pairfob 的电脑。官方中继是托管在 Cloudflare 上的 **pairfob.com**。

## 内容与密钥

配对凭据和会话加密密钥保留在你的电脑与已配对设备上。终端内容、Agent 对话、文件和命令通过加密信封传输；中继只负责转发，不解密或查看内容。电脑在本地保存设备列表和推送订阅，浏览器在本地保存配对凭据和偏好设置。

## 服务元数据与使用统计

端到端加密不隐藏连接元数据。服务会处理电脑标识、连接时间、帧大小、错误和网络地址。注册记录包含 daemon 标识、注册时间、授权关联、撤销状态，以及用于防滥用的 IP 哈希。重置电脑身份会产生新的注册记录，因此这些记录不代表唯一的人或物理电脑。

服务还记录每个身份首次**观测到手机认证连接**的时间，以及最近在中继上观测到的连接活动时间；正常运行时，活动时间最多每五分钟更新一次。心跳也算连接活动，并不代表你输入了什么或完成了多少工作。切换到 P2P 直连后，该会话的活动不再对中继可见。对于旧安装，首次观测时间不一定是真正的首次配对时间。

网站和应用会向本站发送页面类别、配对结果、重连和部分功能打开情况等统计。这些统计使用预定义标签，不包含命令、文件或对话正文。运行日志还可能包含请求元数据，包括 URL；请勿公开分享配对链接或日志。

这些记录用于服务运维、防滥用，以及了解注册到成功连接的转化。汇总转化数据的接口需要管理员认证。

## 保存期限

- 注册及首次、最近连接记录目前没有自动过期机制，在服务维护者删除前会保留。
- Analytics Engine 事件记录保留三个月。运行日志另按服务配置的 Cloudflare 日志保存期限处理。
- 本地凭据与偏好保留到你删除为止。取消配对会撤销设备访问权限，不会自动删除历史服务统计。

如需询问服务保存的记录或提出删除请求，可通过项目的 [GitHub](https://github.com/arronKler/pairfob) 联系维护者。请勿在公开 issue 中发布配对码、密钥、订阅地址或私人内容。

## 通知

电脑端默认具备发送通知的能力，但浏览器仍需获得你的授权并建立订阅才能接收。引导卡片中的“稍后”不会授予权限。你可以关闭电脑端发送，或在设备上撤销通知权限，具体见[通知](/zh/push)。

电脑将加密的 Web Push 内容直接发送给浏览器选择的推送服务商，例如 Apple 或 Google。服务商负责投递并可观测投递元数据；通知内容在设备上解密，是否显示在锁屏上由系统设置决定。中继不保存电脑的推送私钥。
